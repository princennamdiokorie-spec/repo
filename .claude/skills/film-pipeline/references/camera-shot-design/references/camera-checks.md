# Проверки камеры

## Координаты и время

Измерять evaluated world matrix камеры, включая родителя и constraints. Указывать единицы, порядок компонент quaternion и направление осей. Для позиции героя использовать ту же систему.

Для непрерывного диапазона f_start…f_end число кадров N=f_end-f_start+1. При постоянном fps длительность видео N/fps, время между первым и последним отсчётом (N-1)/fps. Фактический файл проверить по метаданным: имя «360f» не доказывает наличие 360 кадров.

Шаг движения делить на фактический интервал времени. Для quaternion сначала нормировать, затем использовать угол 2*acos(abs(dot(q0,q1))); q и -q задают одну ориентацию. Не диагностировать скачок по разности Euler через границу ±180°.

## Надир и наведение

В точном надире горизонтальное направление взгляда вырождено. Обычный look-at с почти параллельным up-вектором может перевернуть базис. Задать согласованную ориентацию сверху и непрерывный переход; не менять fallback-ось посреди шота. Проверить знак quaternion, угловую скорость, переходы и крен на рендерах.

Экранная координата может быть недостижима при заданных положении, крене и объективе. Проверить область решений до итерационного наведения. Ограничить число итераций, проверять положительную глубину, остаток ошибки и непрерывность соседних решений. При неудаче пересмотреть постановку, а не выбирать скрытую ветвь решения с героем за камерой.

Сглаживание кривой не устраняет неверный маршрут. Проверить суммарный пройденный путь, боковую экскурсию и возвраты с учётом драматургии, а также визуальное ускорение при приближении.

## Проекция и ограничения

Для обlique-ракурса проецировать реальные вершины или ориентированные углы бейджа/реквизита с текущим sensor fit, aspect и pixel aspect. Оценка pixels≈f*width/depth без ракурса завышает читаемость наклонного бейджа. Наличие прямоугольника нужной ширины не доказывает читаемость текста.

Bounding box полезен для консервативного поиска опасных кадров, но может давать ложное обрезание. Проверить реальные контуры/вершины и изображение. Координата центра головы не доказывает запас над причёской.

Различать: пересечение геометрии, достаточный зазор объектива, видимость объекта и композицию. Проверить движущиеся препятствия на соответствующем кадре. Не выдавать проверку статического BVH за проверку всех анимированных препятствий.

## JSON для inspect_camera_samples.py

```json
{
  "fps": 24,
  "position_epsilon_m": 0.0001,
  "angle_epsilon_deg": 0.01,
  "hold_start": 180,
  "samples": [
    {"frame": 180, "position": [0, 0, 2], "quaternion": [1, 0, 0, 0]},
    {"frame": 181, "position": [0, 0, 2], "quaternion": [-1, 0, 0, 0]}
  ]
}
```

Quaternion — w,x,y,z; position — метры. Указывать возрастающие номера кадров, не менее двух отсчётов. Для проверки всего шота выгружать каждый кадр, включая начало удержания. При разреженной выборке скрипт сообщает неполное покрытие; неподвижность измерена только между имеющимися отсчётами. Отчёт не получает статус «шот принят».
