# Свидетельства проверки

## Минимальная запись

Для шота указать asset/file, version/hash/revision, камеру, разрешение, fps, диапазон. Для замечания: требование; кадр или интервал; наблюдение; метод; источник изображения/измерения; статус; предлагаемую правку. Не создавать артефакт или ID, которого не было в ответе сервиса.

## Выбор кадров

Начать с начала, конца и переходов; добавить кадры максимального приближения к геометрии, краям и реквизиту. Использовать измерения для поиска экстремумов, затем просмотреть найденные кадры. Изменения направления/скорости смотреть в движении вокруг события, не по одному стоп-кадру.

Редкая контактная таблица не доказывает отсутствие однокадровых дефектов. Если полный просмотр невозможен, точно указать выборку и остаточный риск. Если доступен полный ролик, сопоставить контактную таблицу с просмотром последовательности.

## Уровни доказательства

- Успешный скрипт: выполнился код; это не визуальная оценка.
- Проекция: положение в кадре; сама по себе не доказывает отсутствие окклюзии.
- BVH/пересечения: геометрический контакт в охваченной сцене и времени; это не композиционная оценка.
- Рендер Workbench: форма и кадр; это не проверка финального освещения.
- Рендер delivery camera: изображение конкретного кадра и версии; это не весь ролик.
- Проверенный экспорт: подтверждает свойства этого файла, не автоматически свойства другой revision.
- Качество AI-конверсии: устанавливается по сгенерированному результату; нельзя вывести из превиза.

## Повторная проверка

После изменения камеры прежние выводы о кадрировании больше не действуют для новой камеры. При смене только текста бейджа не повторять весь ранее принятый эксперимент точности Seedance: проверить читаемость и затронутые кадры. Остановиться после проверки конкретных рисков.
