# Reference and casting evaluation

Compare candidates using the same evidence and label each criterion supported, uncertain, or mismatch; cite frames or asset IDs.

| Criterion | Check |
| --- | --- |
| Identity | Stable proportions and distinctive marks from front to profile? |
| Age | Plausible in neutral expression, motion, and posture? |
| Performance | Expression and physical action serve the dramatic task? |
| Scale | Stature and proportions read against known people and props? |
| Robustness | Identity survives light, lens, occlusion, wardrobe, and motion? |
| Production | Needed views, rights, and approved sources available? |

A flattering portrait alone does not establish profile, gait, range, or full-body proportions. For age variants compare invariant eye spacing, nose bridge, jaw pattern, and asymmetry against permitted changes in skin, hair, fullness, and movement. Inspect neutral front, three-quarter, profile, full-length, and one scene expression where available. Mark missing views unverified.

Sample generated shots at opening, turns, closeups, occlusion transitions, contact, and last frame. Log timecode, mismatch, authoritative reference, impact, minimal correction, and approval owner. Prioritize identity swaps, age drift, wrong wardrobe/text, impossible contact, and reversed prop state. Revise one shot for local failures; revise the shared reference pack when the same ambiguity affects many shots.

For a project such as «Люда», treat height, age, uniform, badge, hairstyle, and sports costume as source-bound facts, not defaults. Read current project files before asserting values; remembered summaries can be stale.
